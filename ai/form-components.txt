FORM COMPONENTS
===============

CRITICAL: All form components support two-way binding with bind:value or bind:checked

TEXT INPUT COMPONENTS
---------------------
TextField - Single-line text input
Textarea - Multi-line text input
NumberField - Numeric input with steppers
Search - Search input field

TEXT FIELD
----------
import { TextField } from "svelte-fluentui"

Basic usage:
<TextField placeholder="Enter text" />

With label:
<TextField label="Username" placeholder="Enter username" />

Two-way binding:
let username = $state("")
<TextField bind:value={username} label="Username" />

Props:
value?: string              // Input value (bindable)
placeholder?: string        // Placeholder text
appearance?: "outline" | "filled"
disabled?: boolean
readonly?: boolean
required?: boolean
type?: string              // text, password, email, tel, url
name?: string              // Form name
autocomplete?: string      // Browser autocomplete (e.g., "off", "email")
label?: string             // Visible label
autofocus?: boolean        // Auto focus on mount
style?: string

Events:
onInput?: (ev: InputEvent) => void
onChange?: (ev: Event) => void
onKeyDown?: (ev: KeyboardEvent) => void
onKeyUp?: (ev: KeyboardEvent) => void
onFocus?: (ev: FocusEvent) => void
onBlur?: (ev: FocusEvent) => void

Methods:
select() - Select all text
checkValidity() - Check validity
reportValidity() - Report validity
setCustomValidity(message) - Set custom error

Example with validation:
<script>
let email = $state("")
let emailField: any

function handleSubmit() {
    if (!emailField.checkValidity()) {
        emailField.reportValidity()
        return
    }
    // Submit form
}
</script>

<TextField
    bind:this={emailField}
    bind:value={email}
    type="email"
    required
    label="Email"
/>
<Button onclick={handleSubmit}>Submit</Button>

AUTOCOMPLETE
------------
import { Autocomplete } from "svelte-fluentui"

Multi-select with chips:
<script>
const countries = [
    { value: "us", text: "United States" },
    { value: "uk", text: "United Kingdom" },
    { value: "ca", text: "Canada" }
]

let selected = $state<string[]>([])
</script>

<Autocomplete
    bind:selectedOptions={selected}
    options={countries}
    label="Select countries"
    placeholder="Type to search..."
    maxSelectedOptions={5}
/>

Initial options with async search:
<script>
// Popular items shown initially
const popularCountries = [
    { value: "us", text: "United States" },
    { value: "uk", text: "United Kingdom" },
    { value: "ca", text: "Canada" }
]

let selected = $state<string[]>([])

// Called when user types
async function searchAllCountries(searchText: string) {
    const response = await fetch('/api/countries?q=' + searchText)
    return await response.json()
}
</script>

<Autocomplete
    bind:selectedOptions={selected}
    options={popularCountries}
    onOptionsSearch={searchAllCountries}
    showInitialOptions={true}
    initialOptionsCount={5}
    label="Select country"
    placeholder="Select from popular or search all..."
/>

Props:
options?: OptionItem[]                // Available options
selectedOptions?: T[]                 // Selected options (bindable)
placeholder?: string
disabled?: boolean
readonly?: boolean
required?: boolean
label?: string
appearance?: string
maxSelectedOptions?: number           // Max selections allowed
maxOptionsSearch?: number             // Max results shown (default: 9)
showOverlayOnEmptyResults?: boolean   // Show dropdown when empty (default: true)
showInitialOptions?: boolean          // Show options when empty (default: false)
initialOptionsCount?: number          // Limit initial options (default: maxOptionsSearch)
keepOpen?: boolean                    // Keep dropdown open after selection
width?: string                        // Custom width
class?: string
style?: string

Events:
onOptionsSearch?: (searchText: string) => Promise<OptionItem[]> | OptionItem[]
onSelectedOptionsChange?: (selected: T[]) => void

OptionItem type:
{
    value: T          // Unique identifier
    text: string      // Display text
    disabled?: boolean // Optional disabled state
}

let allChecked = $state<boolean | null>(null)

    if (allChecked === true) allChecked = null

    else allChecked = true
}

    bind:checked={allChecked}
    indeterminate={allChecked === null}

    Select All
</Checkbox>

FILE UPLOAD
-----------
import { InputFile } from "svelte-fluentui"

Basic usage:
<InputFile label="Upload files" />

Props:
accept?: string              // File types (e.g., ".pdf,.doc")
multiple?: boolean           // Allow multiple files
maxFileSize?: number         // Max size in bytes
maxFiles?: number           // Max file count
disabled?: boolean
label?: string

Events:
onFileSelected?: (files: File[]) => void
onFileUploaded?: (file: File) => void
onFileError?: (file: File, error: string) => void
onCompleted?: () => void

With upload callback:
<script>
async function uploadFile(file: File): Promise<void> {
    const formData = new FormData()
    formData.append("file", file)

    const response = await fetch("/api/upload", {
        method: "POST",
        body: formData
    })

    if (!response.ok) {
        throw new Error("Upload failed")
    }
}
</script>

<InputFile
    label="Upload document"
    accept=".pdf,.doc,.docx"
    maxFileSize={5 * 1024 * 1024}
    uploadCallback={uploadFile}
/>

FORM VALIDATION
---------------
HTML5 validation:
<TextField
    type="email"
    required
    pattern="[a-z0-9._%+-]+@[a-z0-9.-]+\.[a-z]{2,}$"
/>

Custom validation:
<script>
let emailField: any

function validateEmail() {
    if (!email.includes("@")) {
        emailField.setCustomValidity("Invalid email")
        emailField.reportValidity()
        return false
    }
    emailField.setCustomValidity("")
    return true
}
</script>

<TextField
    bind:this={emailField}
    bind:value={email}
    type="email"
    onBlur={validateEmail}
/>

FORM SUBMISSION
---------------
Complete form example:
<script>
import { TextField, Checkbox, Button, Stack, toast } from "svelte-fluentui"

let username = $state("")
let email = $state("")
let remember = $state(false)

async function handleSubmit() {
    const formData = { username, email, remember }

    try {
        const response = await fetch("/api/register", {
            method: "POST",
            headers: { "Content-Type": "application/json" },
            body: JSON.stringify(formData)
        })

        if (response.ok) {
            toast.success("Registration successful!")
        } else {
            toast.error("Registration failed")
        }
    } catch (error) {
        toast.error("Network error")
    }
}
</script>

<Stack orientation="vertical" gap="1rem">
    <TextField
        bind:value={username}
        label="Username"
        required
        autocomplete="username"
    />
    <TextField
        bind:value={email}
        type="email"
        label="Email"
        required
        autocomplete="email"
    />
    <Checkbox bind:checked={remember}>
        Remember me
    </Checkbox>
    <Button appearance="accent" onclick={handleSubmit}>
        Register
    </Button>
</Stack>

BEST PRACTICES
--------------
- Use bind:value for two-way binding
- Add labels for accessibility
- Use autocomplete for better UX
- Validate inputs with HTML5 attributes
- Disable autocomplete with autocomplete="off"
- Use appropriate input types (email, tel, url)
- Add placeholder text for clarity
- Use required for mandatory fields
- Provide custom validation messages
- Handle form submission with async/await
