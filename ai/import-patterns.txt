THEME CUSTOMIZATION
-------------------
Override variables with @use...with():

// custom-theme.scss
@use 'svelte-fluentui/theme' with (
    $navbar-bg-light: #FFCC00,
    $sidebar-bg: #333,
    $accent-color: #0078d4
);
@use 'svelte-fluentui/fluent-ui';
@use 'svelte-fluentui/layout';
@use 'svelte-fluentui/nav';
@use 'svelte-fluentui/components';

Then import your custom file:
import "./custom-theme.scss"

COMMON IMPORT ERRORS
--------------------
Error: "Cannot find module 'svelte-fluentui/Button'"
Fix: Import from main module

❌ import Button from "svelte-fluentui/Button"
✅ import { Button } from "svelte-fluentui"

Error: "Cannot find module 'svelte-fluentui/styles.css'"
Fix: Use correct style path

❌ import "svelte-fluentui/styles.css"
✅ import "svelte-fluentui/styles.scss"
✅ import "svelte-fluentui/styles"

Error: "Styles not applied"
Fix: Import styles before components

❌ Wrong order:
import { Button } from "svelte-fluentui"
import "svelte-fluentui/styles.scss"

✅ Correct order:
import "svelte-fluentui/styles.scss"
import { Button } from "svelte-fluentui"

Error: "Cannot override SCSS variables"
Fix: Import individual SCSS modules with @use

❌ import "svelte-fluentui/styles.scss" then try to override
✅ Use @use with variables:
@use 'svelte-fluentui/theme' with ($navbar-bg-light: #FFCC00);

Error: "$settings is not defined"
Fix: Use settings without $ (it's not a Svelte store)

❌ const theme = $settings.themeMode
✅ const theme = $settings.themeMode  // Actually this works if in reactive context
✅ const currentSettings = $settings  // Get snapshot

Actually, settings IS a store:
const currentSettings = $derived($settings)

Error: "toast is not a function"
Fix: Use toast service methods

❌ toast("Message")
✅ toast.success("Message")
✅ toast.error("Message")

    Layout,

    BodyContent,
    Footer,

TREE SHAKING
------------
Package uses ES modules for tree shaking.
Import only what you use:

✅ import { Button, TextField } from "svelte-fluentui"
   // Only Button and TextField bundled

❌ import * as FluentUI from "svelte-fluentui"
   // Entire library bundled

BEST PRACTICES
--------------
- Import styles in root layout only (once)
- Import components from main module
- Use short SCSS paths for customization
- Import only components you use
- Use @use...with() for variable overrides
- Import design tokens from @fluentui/web-components
- Use TypeScript types for better DX
- Don't import styles multiple times
- Prefer SCSS over CSS for flexibility
- Follow import order: styles → framework → components → utils
