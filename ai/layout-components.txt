LAYOUT COMPONENTS
=================

CRITICAL: Layout components are custom implementations, NOT FluentUI wrappers

MAIN LAYOUT COMPONENTS
----------------------
Layout - Page layout container
Header - Page header section
Footer - Page footer section
BodyContent - Main content wrapper
Grid - 12-column responsive grid
GridItem - Grid column
Stack - Flexbox container
Spacer - Flexible spacing
MultiSplitter - Resizable panels

LAYOUT
------
import { Layout } from "svelte-fluentui"

Container for page structure:
<Layout orientation="vertical" style="min-height: 100vh;">
    <Header>Header</Header>
    <BodyContent>Content</BodyContent>
    <Footer>Footer</Footer>
</Layout>

Props:
orientation?: "vertical" | "horizontal"   // Default: vertical
gap?: string                               // Spacing between children
style?: string
class?: string

Vertical layout (most common):
<Layout orientation="vertical">
    <!-- Children stack vertically -->
</Layout>

Horizontal layout:
<Layout orientation="horizontal">
    <!-- Children arrange horizontally -->
</Layout>

GRID SYSTEM
-----------
import { Grid, GridItem } from "svelte-fluentui"

12-column responsive grid:
<Grid spacing={3}>
    <GridItem xs={12} md={6} lg={4}>
        Column 1
    </GridItem>
    <GridItem xs={12} md={6} lg={4}>
        Column 2
    </GridItem>
    <GridItem xs={12} md={12} lg={4}>
        Column 3
    </GridItem>
</Grid>

GRID PROPS
----------
spacing?: number              // Gap between items (0-5)
class?: string
style?: string

Spacing scale:
0 = 0rem
1 = 0.5rem
2 = 1rem
3 = 1.5rem
4 = 2rem
5 = 3rem

GRIDITEM PROPS
--------------
xs?: number    // Extra small screens (0px+)      1-12 columns
sm?: number    // Small screens (576px+)          1-12 columns
md?: number    // Medium screens (768px+)         1-12 columns
lg?: number    // Large screens (992px+)          1-12 columns
xl?: number    // Extra large screens (1200px+)   1-12 columns
xxl?: number   // XXL screens (1400px+)           1-12 columns

class?: string
style?: string

BREAKPOINTS
-----------
xs: 0px+       // Mobile portrait
sm: 576px+     // Mobile landscape
md: 768px+     // Tablet
lg: 992px+     // Desktop
xl: 1200px+    // Large desktop
xxl: 1400px+   // Extra large

STACK
-----
import { Stack } from "svelte-fluentui"

Flexbox layout (vertical or horizontal):
<Stack orientation="vertical" gap="1rem">
    <div>Item 1</div>
    <div>Item 2</div>
    <div>Item 3</div>
</Stack>

Props:
orientation?: "vertical" | "horizontal"   // Default: vertical
gap?: string                               // Space between items
horizontalAlign?: "start" | "center" | "end" | "stretch"
verticalAlign?: "start" | "center" | "end" | "stretch"
wrap?: boolean                             // Allow wrapping
class?: string
style?: string

Vertical stack (default):
<Stack orientation="vertical" gap="1rem">
    <Card>Card 1</Card>
    <Card>Card 2</Card>
</Stack>

Horizontal stack:
<Stack orientation="horizontal" gap="0.5rem">
    <Button>Cancel</Button>
    <Button appearance="accent">Save</Button>
</Stack>

Centered stack:
<Stack
    orientation="vertical"
    horizontalAlign="center"
    verticalAlign="center"
    gap="2rem"
>
    <h1>Welcome</h1>
    <Button>Get Started</Button>
</Stack>

Horizontal alignment (for vertical stack):
<Stack orientation="vertical" horizontalAlign="center">
    Items centered horizontally
</Stack>

Vertical alignment (for horizontal stack):
<Stack orientation="horizontal" verticalAlign="center">
    Items centered vertically
</Stack>

Wrapping stack:
<Stack orientation="horizontal" wrap={true} gap="1rem">
    <Button>Button 1</Button>
    <Button>Button 2</Button>
    <Button>Button 3</Button>
    <!-- Wraps to next row if needed -->
</Stack>

MULTISPLITTER
-------------
import { MultiSplitter, MultiSplitterPane } from "svelte-fluentui"

Resizable panels:
<MultiSplitter orientation="horizontal">
    <MultiSplitterPane initialSize="300px" minSize="200px">
        Sidebar
    </MultiSplitterPane>
    <MultiSplitterPane>
        Main content (takes remaining space)
    </MultiSplitterPane>
</MultiSplitter>

MULTISPLITTER PROPS
-------------------
orientation?: "horizontal" | "vertical"   // Default: horizontal
class?: string
style?: string

MULTISPLITTERPANE PROPS
-----------------------
initialSize?: string      // Initial size (e.g., "300px", "30%")
minSize?: string         // Minimum size
maxSize?: string         // Maximum size
class?: string
style?: string

Horizontal splitter (side-by-side):
<MultiSplitter orientation="horizontal" style="height: 600px;">
    <MultiSplitterPane initialSize="250px" minSize="200px">
        Left panel
    </MultiSplitterPane>
    <MultiSplitterPane>
        Middle panel
    </MultiSplitterPane>
    <MultiSplitterPane initialSize="300px">
        Right panel
    </MultiSplitterPane>
</MultiSplitter>

Vertical splitter (top/bottom):
<MultiSplitter orientation="vertical" style="height: 600px;">
    <MultiSplitterPane initialSize="200px">
        Top panel
    </MultiSplitterPane>
    <MultiSplitterPane>
        Bottom panel
    </MultiSplitterPane>
</MultiSplitter>

RESPONSIVE PATTERNS
-------------------
Mobile-first approach:
<Grid spacing={3}>
    <GridItem xs={12} md={6} lg={4}>
        <!-- 100% mobile, 50% tablet, 33% desktop -->
    </GridItem>
</Grid>

Hide on mobile:
<GridItem xs={0} md={3}>
    <!-- Hidden on mobile, 25% on tablet+ -->
</GridItem>

Full-width on mobile, split on desktop:
<Grid spacing={2}>
    <GridItem xs={12} lg={6}>Column 1</GridItem>
    <GridItem xs={12} lg={6}>Column 2</GridItem>
</Grid>

COMMON LAYOUT ERRORS
--------------------
Error: "Grid items not aligning"
Fix: Ensure column numbers sum to 12 or less

❌ <GridItem lg={8} /><GridItem lg={6} />  // 14 total!
✅ <GridItem lg={8} /><GridItem lg={4} />  // 12 total

Error: "Stack items not spacing"
Fix: Use gap prop, not CSS margin

❌ <Stack><div style="margin: 1rem">Item</div></Stack>
✅ <Stack gap="1rem"><div>Item</div></Stack>

Error: "Splitter not resizing"
Fix: Set explicit height on MultiSplitter

❌ <MultiSplitter>...</MultiSplitter>
✅ <MultiSplitter style="height: 600px">...</MultiSplitter>

Error: "Layout not full height"
Fix: Use min-height: 100vh on Layout

❌ <Layout orientation="vertical">
✅ <Layout orientation="vertical" style="min-height: 100vh;">

BEST PRACTICES
--------------
- Use Layout for page structure
- Use Grid for responsive layouts
- Use Stack for simple vertical/horizontal arrangements
- Use Spacer to push items apart in Stack
- Use MultiSplitter for resizable panels
- Start with xs breakpoint (mobile-first)
- Ensure grid columns sum to 12
- Set explicit height on MultiSplitter
- Use gap prop for consistent spacing
- Test layouts on multiple screen sizes
