BASIC SETUP
===========

CRITICAL: This is a Svelte 5 library using RUNES
- Use $state(), $derived(), $effect()
- NO writable(), readable(), derived()
- NO $: reactive declarations
- NO $store syntax

INSTALLATION
------------
npm install svelte-fluentui

Peer dependencies (install separately):
npm install @fluentui/web-components

BASIC USAGE
-----------
// +layout.svelte or App.svelte
<script>
import "svelte-fluentui/styles.scss"  // SCSS (recommended)
// OR
import "svelte-fluentui/styles"       // CSS (no variable overrides)

import { Button, TextField, Card } from "svelte-fluentui"
</script>

<Card>
    <TextField placeholder="Enter text" />
    <Button appearance="accent">Submit</Button>
</Card>

IMPORT STYLES FIRST
-------------------
CRITICAL: Import styles BEFORE components!

✅ Correct order:
import "svelte-fluentui/styles.scss"
import { Button } from "svelte-fluentui"

❌ Wrong order:
import { Button } from "svelte-fluentui"
import "svelte-fluentui/styles.scss"  // Too late!

SCSS VS CSS
-----------
SCSS (recommended):
import "svelte-fluentui/styles.scss"

Benefits:
- Can override variables with @use...with()
- Full theme customization
- Compile-time variable resolution

CSS (simple):
import "svelte-fluentui/styles"

Benefits:
- No SCSS processor needed
- Faster build if no customization
- Good for quick prototypes

THEME SETUP
-----------
Apply FluentUI theme in root layout:

<script>
import "svelte-fluentui/styles.scss"
import { onMount } from "svelte"
import { baseLayerLuminance, StandardLuminance } from "@fluentui/web-components"

onMount(() => {
    // Set theme (light or dark)
    baseLayerLuminance.setValueFor(
        document.documentElement,
        StandardLuminance.LightMode  // or StandardLuminance.DarkMode
    )
})
</script>

FORM EXAMPLE
------------
<script>
import { TextField, Checkbox, Button, Stack } from "svelte-fluentui"

let username = $state("")
let remember = $state(false)

function handleSubmit() {
    console.log({ username, remember })
}
</script>

<Stack orientation="vertical" gap="1rem">
    <TextField
        bind:value={username}
        label="Username"
        required
    />
    <Checkbox bind:checked={remember}>
        Remember me
    </Checkbox>
    <Button appearance="accent" onclick={handleSubmit}>
        Login
    </Button>
</Stack>

COMMON PATTERNS
---------------
Bindable values:
let value = $state("")
<TextField bind:value />

Event handlers:
<TextField onInput={(e) => console.log(e)} />
<Button onclick={handleClick}>Click</Button>

Appearance variants:
<Button appearance="accent">Accent</Button>
<Button appearance="neutral">Neutral</Button>
<Button appearance="outline">Outline</Button>

Disabled state:
<TextField disabled={true} />
<Button disabled={isLoading}>Submit</Button>

Required fields:
<TextField required label="Email" />

VITE CONFIGURATION
------------------
SCSS processing built into Vite, no config needed.

For variable overrides, use @use in your app:

// src/styles/custom.scss
@use 'svelte-fluentui/theme' with (
    $navbar-bg-light: #FFCC00
);

Then import your custom file:
import "./styles/custom.scss"

COMMON SETUP ERRORS
-------------------
Error: "Failed to resolve import"
Fix: Install peer dependency @fluentui/web-components

❌ npm install svelte-fluentui
✅ npm install svelte-fluentui @fluentui/web-components

Error: "Styles not applied"
Fix: Import styles before components

❌ Import components first, then styles
✅ Import styles first, then components

Error: "Cannot override variables"
Fix: Use .scss import, not .css

❌ import "svelte-fluentui/styles"
✅ import "svelte-fluentui/styles.scss"

Error: "Theme not applied"
Fix: Set baseLayerLuminance on document.documentElement

❌ baseLayerLuminance.setValueFor(element, ...)
✅ baseLayerLuminance.setValueFor(document.documentElement, ...)

BEST PRACTICES
--------------
- Import styles in root layout only (once)
- Use SCSS for variable customization
- Set theme in onMount to avoid FOUC
- Use Grid/GridItem for responsive layouts
- Use Stack for simple vertical/horizontal layouts
- Bind values with bind:value for two-way binding
- Use ToastContainer once in root layout
- Import only components you use (tree-shaking)
- Use TypeScript for better DX
- Follow FluentUI design patterns
