DATA COMPONENTS
===============

CRITICAL: QuickGrid is a custom component, DataGrid wraps FluentUI web component

DATA DISPLAY COMPONENTS
-----------------------
QuickGrid - Advanced data grid with sorting, filtering, pagination
DataGrid - FluentUI data grid wrapper
DataGridRow - Data grid row
DataGridCell - Data grid cell
Paginator - Pagination control
Toolbar - Toolbar container

QUICKGRID
---------
import { QuickGrid } from "svelte-fluentui"

Advanced grid with built-in features:
<script>
type User = {
    id: number
    name: string
    email: string
    role: string
}

const users: User[] = [
    { id: 1, name: "John Doe", email: "john@example.com", role: "Admin" },
    { id: 2, name: "Jane Smith", email: "jane@example.com", role: "User" }
]

const columns = [
    { field: "id", title: "ID", sortable: true },
    { field: "name", title: "Name", sortable: true, filterable: true },
    { field: "email", title: "Email", filterable: true },
    { field: "role", title: "Role", sortable: true, filterable: true }
]
</script>

<QuickGrid
    items={users}
    {columns}
    sortable
    filterable
    striped
/>

QUICKGRID PROPS
---------------
items: T[]                    // Data array (required)
columns: Column<T>[]          // Column definitions (required)
sortable?: boolean            // Enable sorting (default: false)
filterable?: boolean          // Enable filtering (default: false)
pagination?: boolean          // Enable pagination (default: false)
pageSize?: number             // Items per page (default: 10)
striped?: boolean             // Striped rows (default: false)
hoverable?: boolean           // Hover effect (default: false)
class?: string
style?: string

COLUMN DEFINITION
-----------------
type Column<T> = {
    field: keyof T | string          // Property name
    title: string                     // Column header
    sortable?: boolean                // Allow sorting
    filterable?: boolean              // Allow filtering
    format?: (value: any, row: T) => string     // Custom formatting
    template?: (row: T) => string     // HTML template
}

Basic columns:
const columns = [
    { field: "id", title: "ID" },
    { field: "name", title: "Name" },
    { field: "email", title: "Email" }
]

Sortable columns:
const columns = [
    { field: "id", title: "ID", sortable: true },
    { field: "name", title: "Name", sortable: true },
    { field: "email", title: "Email" }
]

Filterable columns:
const columns = [
    { field: "name", title: "Name", filterable: true },
    { field: "email", title: "Email", filterable: true }
]

Custom formatting:
const columns = [
    {
        field: "createdAt",
        title: "Created",
        format: (value: string) => new Date(value).toLocaleDateString()
    },
    {
        field: "price",
        title: "Price",
        format: (value: number) => `$${value.toFixed(2)}`
    }
]

HTML template (for links, buttons):
const columns = [
    {
        field: "name",
        title: "Name",
        template: (row: User) => `<a href="/users/${row.id}">${row.name}</a>`
    },
    {
        field: "id",
        title: "Actions",
        template: (row: User) => `<button data-id="${row.id}">Edit</button>`
    }
]

SORTING
-------
Client-side sorting (default):
<QuickGrid
    items={users}
    columns={columns}
    sortable
/>

Sorting supports:
- String values (alphabetical)
- Number values (numeric)
- Mixed types (handles gracefully)

Initial sort:
<script>
let sortField = $state("name")
let sortDirection = $state<"asc" | "desc">("asc")
</script>

<QuickGrid
    items={users}
    columns={columns}
    sortable
    bind:sortField
    bind:sortDirection
/>

FILTERING
---------
Client-side filtering:
<QuickGrid
    items={users}
    columns={columns}
    filterable
/>

Filter applies to all filterable columns (case-insensitive).

PAGINATION
----------
Built-in pagination:
<QuickGrid
    items={users}
    columns={columns}
    pagination
    pageSize={10}
/>

Custom page size:
<QuickGrid
    items={users}
    columns={columns}
    pagination
    pageSize={25}
/>

COMPLETE QUICKGRID EXAMPLE
--------------------------
<script>
import { QuickGrid, Card } from "svelte-fluentui"

type Product = {
    id: number
    name: string
    category: string
    price: number
    stock: number
    createdAt: string
}

const products: Product[] = [
    { id: 1, name: "Laptop", category: "Electronics", price: 999.99, stock: 15, createdAt: "2025-01-15" },
    { id: 2, name: "Mouse", category: "Accessories", price: 29.99, stock: 50, createdAt: "2025-01-10" },
    { id: 3, name: "Keyboard", category: "Accessories", price: 79.99, stock: 30, createdAt: "2025-01-12" }
]

const columns = [
    { field: "id", title: "ID", sortable: true },
    {
        field: "name",
        title: "Product Name",
        sortable: true,
        filterable: true,
        template: (row: Product) => `<a href="/products/${row.id}" class="product-link">${row.name}</a>`
    },
    {
        field: "category",
        title: "Category",
        sortable: true,
        filterable: true
    },
    {
        field: "price",
        title: "Price",
        sortable: true,
        format: (value: number) => `$${value.toFixed(2)}`
    },
    {
        field: "stock",
        title: "Stock",
        sortable: true,
        format: (value: number) => value > 20 ? `${value} ✅` : `${value} ⚠️`
    },
    {
        field: "createdAt",
        title: "Created",
        sortable: true,
        format: (value: string) => new Date(value).toLocaleDateString()
    }
]
</script>

<Card>
    <h2>Product Inventory</h2>
    <QuickGrid
        items={products}
        {columns}
        sortable
        filterable
        pagination
        pageSize={10}
        striped
        hoverable
    />
</Card>

<style>
:global(.product-link) {
    color: var(--accent-fill-rest);
    text-decoration: none;
    font-weight: 500;
}

:global(.product-link:hover) {
    text-decoration: underline;
}
</style>

PAGINATOR
---------
import { Paginator } from "svelte-fluentui"

Pagination control:
<script>
let currentPage = $state(1)
const totalItems = 100
const pageSize = 10
const totalPages = Math.ceil(totalItems / pageSize)
</script>

<Paginator
    bind:currentPage
    {totalPages}
/>

Props:
currentPage: number          // Current page (bindable)
totalPages: number           // Total page count
class?: string
style?: string

Manual pagination example:
<script>
import { Paginator } from "svelte-fluentui"

const allItems = [...Array(100)].map((_, i) => ({ id: i, name: `Item ${i}` }))
let currentPage = $state(1)
const pageSize = 10

const paginatedItems = $derived(() => {
    const start = (currentPage - 1) * pageSize
    return allItems.slice(start, start + pageSize)
})

const totalPages = Math.ceil(allItems.length / pageSize)
</script>

{#each paginatedItems as item}
    <div>{item.name}</div>
{/each}

<Paginator bind:currentPage {totalPages} />

DATA PATTERNS
-------------
CRUD operations:
<script>
import { QuickGrid, Button, Stack, Dialog } from "svelte-fluentui"

let users = $state([...])
let selectedUser = $state(null)
let dialogOpen = $state(false)

function editUser(user) {
    selectedUser = user
    dialogOpen = true
}

function deleteUser(userId) {
    users = users.filter(u => u.id !== userId)
}

const columns = [
    { field: "name", title: "Name", sortable: true },
    { field: "email", title: "Email", filterable: true },
    {
        field: "id",
        title: "Actions",
        template: (row) => `
            <button data-action="edit" data-id="${row.id}">Edit</button>
            <button data-action="delete" data-id="${row.id}">Delete</button>
        `
    }
]
</script>

<Stack orientation="vertical" gap="1rem">
    <Toolbar>
        <Button appearance="accent" onclick={() => dialogOpen = true}>
            Add User
        </Button>
    </Toolbar>

    <QuickGrid
        items={users}
        {columns}
        sortable
        filterable
    />
</Stack>

Server-side data:
<script>
import { QuickGrid } from "svelte-fluentui"
import { onMount } from "svelte"

let data = $state([])
let loading = $state(true)

onMount(async () => {
    const response = await fetch("/api/users")
    data = await response.json()
    loading = false
})
</script>

{#if loading}
    <p>Loading...</p>
{:else}
    <QuickGrid
        items={data}
        columns={columns}
        sortable
        filterable
        pagination
    />
{/if}

COMMON DATA ERRORS
------------------
Error: "Columns not displaying"
Fix: Ensure field matches data property

❌ { field: "userName", title: "Name" }  // data has "name"
✅ { field: "name", title: "Name" }

Error: "Template not rendering"
Fix: Template returns HTML string

❌ template: (row) => row.name  // Not HTML
✅ template: (row) => `<a href="#">${row.name}</a>`

Error: "Pagination not working"
Fix: Enable pagination prop

❌ <QuickGrid items={data} columns={columns} />
✅ <QuickGrid items={data} columns={columns} pagination />

BEST PRACTICES
--------------
- Use QuickGrid for most data grids
- Add sortable to frequently sorted columns
- Add filterable to searchable columns
- Use pagination for large datasets
- Format numbers, dates with format function
- Use template for links and actions
- Keep columns under 10 for readability
- Use striped for better row distinction
- Test with empty data arrays
- Handle loading states
