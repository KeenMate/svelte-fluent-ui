NAVIGATION COMPONENTS
=====================

NAVGROUP
--------
import { NavGroup } from "svelte-fluentui"

Collapsible navigation section:
<NavGroup title="Main Menu">
    {#snippet linkIcon()}
        🏠
    {/snippet}
    {#snippet linkText()}
        Main
    {/snippet}

    <NavLinkItem href="/">Home</NavLinkItem>
    <NavLinkItem href="/about">About</NavLinkItem>
</NavGroup>

Props:
title?: string           // Group identifier (for state persistence)
class?: string
style?: string
children?: SlotType
linkIcon?: SlotType      // Icon snippet
linkText?: SlotType      // Text snippet

State persistence:
NavGroup automatically saves expanded/collapsed state to localStorage using the title prop.

Without title (no persistence):
<NavGroup>
    <NavLinkItem href="/">Home</NavLinkItem>
</NavGroup>

With title (persists state):
<NavGroup title="main-menu">
    <NavLinkItem href="/">Home</NavLinkItem>
</NavGroup>

NAVLINKITEM
-----------
import { NavLinkItem } from "svelte-fluentui"

Navigation link:
<NavLinkItem href="/products">Products</NavLinkItem>

Props:
href?: string
target?: string          // e.g., "_blank"
rel?: string            // e.g., "noopener noreferrer"
class?: string
style?: string
children?: SlotType

Active state:
Add "active" class when route matches:

<script>
import { page } from "$app/stores"  // SvelteKit

function isActive(href: string): boolean {
    return $page.url.pathname === href
}
</script>

<NavLinkItem
    href="/about"
    class={isActive("/about") ? "active" : ""}
>
    About
</NavLinkItem>

External links:
<NavLinkItem
    href="https://example.com"
    target="_blank"
    rel="noopener noreferrer"
>
    External Site
</NavLinkItem>

COMPLETE NAVMENU EXAMPLE
------------------------
<script>
import { NavMenu, NavGroup, NavLinkItem } from "svelte-fluentui"
import { page } from "$app/stores"

function isActive(href: string): boolean {
    if (!href) return false
    if (href === "/" && $page.url.pathname === "/") return true
    if (href !== "/" && $page.url.pathname.startsWith(href)) return true
    return false
}

const navigation = [
    {
        title: "Home",
        icon: "🏠",
        items: [
            { label: "Dashboard", href: "/" }
        ]
    },
    {
        title: "Products",
        icon: "📦",
        items: [
            { label: "All Products", href: "/products" },
            { label: "Categories", href: "/products/categories" }
        ]
    }
]
</script>

<NavMenu>
    {#each navigation as group}
        <NavGroup title={group.title}>
            {#snippet linkIcon()}
                <span class="nav-icon">{group.icon}</span>
            {/snippet}
            {#snippet linkText()}
                {group.title}
            {/snippet}

            {#each group.items as item}
                <NavLinkItem
                    href={item.href}
                    class={isActive(item.href) ? "active" : ""}
                >
                    {item.label}
                </NavLinkItem>
            {/each}
        </NavGroup>
    {/each}
</NavMenu>

BREADCRUMBITEM
--------------
import { BreadcrumbItem } from "svelte-fluentui"

Individual breadcrumb:
<BreadcrumbItem href="/products">Products</BreadcrumbItem>

Props:
href?: string
class?: string
style?: string
children?: SlotType

Dynamic breadcrumbs:
<script>
import { page } from "$app/stores"

const breadcrumbs = $derived(() => {
    const segments = $page.url.pathname.split("/").filter(Boolean)
    return segments.map((segment, index) => ({
        label: segment.charAt(0).toUpperCase() + segment.slice(1),
        href: "/" + segments.slice(0, index + 1).join("/")
    }))
})
</script>

<Breadcrumb>
    <BreadcrumbItem href="/">Home</BreadcrumbItem>
    {#each breadcrumbs as crumb}
        <BreadcrumbItem href={crumb.href}>
            {crumb.label}
        </BreadcrumbItem>
    {/each}
</Breadcrumb>

RESPONSIVE NAVIGATION
---------------------
Mobile + Desktop nav:
<script>
let isMobile = $state(false)

onMount(() => {
    isMobile = window.innerWidth < 768
    window.addEventListener("resize", () => {
        isMobile = window.innerWidth < 768
    })
})
</script>

{#if isMobile}
    <!-- Mobile: hamburger menu -->
    <Button onclick={() => menuOpen = !menuOpen}>
        ☰
    </Button>
{:else}
    <!-- Desktop: sidebar -->
    <NavMenu>...</NavMenu>
{/if}

COMMON NAVIGATION ERRORS
-------------------------
Error: "NavGroup not expanding"
Fix: Ensure NavGroup has title prop for state persistence

❌ <NavGroup>...</NavGroup>
✅ <NavGroup title="main-menu">...</NavGroup>

Error: "Active link not highlighting"
Fix: Add active class based on current route

❌ <NavLinkItem href="/about">About</NavLinkItem>
✅ <NavLinkItem href="/about" class={isActive("/about") ? "active" : ""}>

Error: "Tabs not switching"
Fix: Match number of Tab and TabPanel components

❌ 3 Tabs, 2 TabPanels
✅ 3 Tabs, 3 TabPanels

BEST PRACTICES
--------------
- Use NavGroup with title for state persistence
- Add active class to current NavLinkItem
- Use breadcrumbs for deep navigation
- Use tabs for related content sections
- Use accordion for FAQ/expandable content
- Match Tab count with TabPanel count
- Test navigation on mobile devices
- Use external link attributes (target, rel) properly
- Provide clear navigation hierarchy
- Use icons in NavGroup for better UX
