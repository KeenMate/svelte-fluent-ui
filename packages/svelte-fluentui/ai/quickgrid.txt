QUICKGRID COMPONENT
===================

OVERVIEW
--------
Advanced data grid with sorting, filtering, pagination, and inline editing.
Custom implementation (not a FluentUI wrapper).
Inspired by ASP.NET QuickGrid.


BASIC USAGE
-----------
<script>
  import { QuickGrid } from "svelte-fluentui"

  type Person = { id: number, name: string, age: number }

  const columns = [
    { field: "id", title: "ID" },
    { field: "name", title: "Name" },
    { field: "age", title: "Age" }
  ]

  const data: Person[] = [
    { id: 1, name: "Alice", age: 28 },
    { id: 2, name: "Bob", age: 34 }
  ]
</script>

<QuickGrid items={data} {columns} />


PROPS
-----
items: T[]                    # Data array (required)
columns: Column<T>[]          # Column definitions (required)
sortable: boolean             # Enable sorting (default: false)
filterable: boolean           # Enable filtering (default: false)
pageable: boolean             # Enable pagination (default: false)
pageSize: number              # Items per page (default: 10)
striped: boolean              # Striped rows (default: true)
hoverable: boolean            # Row hover effect (default: true)
fillerColumn: boolean         # Append empty trailing column that absorbs leftover
                              # horizontal space. Use with per-column width / autoWidth
                              # to keep columns at their defined widths instead of
                              # justifying across the table (default: false)
class: string                 # Additional CSS classes
style: string                 # Inline styles

EDITING PROPS:
editable: boolean             # Enable editing (default: false)
isRowEditable: boolean | (row) => boolean  # Row-level gate; return false for read-only
                              # rows (e.g. tree-grid parent rows). Default: true
editTrigger: EditTrigger      # How to start editing (default: "dblclick")
dropdownShowOnFocus: boolean  # Auto-open dropdowns (default: true)
checkboxAlwaysEditable: bool  # Checkboxes always clickable (default: false)
invalidCells: CellValidationState[]  # Bindable validation errors

CALLBACKS:
onrowchange: (detail) => void      # Called after cell edit commits
onroweditstart: (detail) => void   # Called when edit starts
onroweditcancel: (detail) => void  # Called when edit cancelled
onvalidationerror: (detail) => void # Called on validation failure


COLUMN INTERFACE
----------------
type Column<T> = {
  field: keyof T | string     # Property name in data
  title: string               # Display header text
  headerInfo?: string         # Tooltip text (shows ⓘ icon)
  sortable?: boolean          # Enable sorting for column
  filterable?: boolean        # Enable filtering for column
  width?: string              # Explicit column width (any CSS length: "100px",
                              # "20%", "10rem", etc.). Ignored when autoWidth is true
  minWidth?: string           # CSS min-width (e.g. "80px")
  maxWidth?: string           # CSS max-width (e.g. "320px")
  autoWidth?: boolean         # Size column to its header content; don't stretch.
                              # Best paired with grid-level fillerColumn
  nowrap?: boolean            # Body cells never wrap. With maxWidth, long content
                              # truncates with an ellipsis. With autoWidth, sizes to
                              # max(header, longest cell). Without maxWidth, very long
                              # cells will widen the column unbounded
  align?: "left" | "center" | "right"

  # Formatting
  format?: (value, row) => string   # Format display value
  template?: (row) => string        # HTML template (use @html)
  snippet?: Snippet<[T]>            # Svelte snippet for cell content

  # Editing
  isEditable?: boolean | ((row: T) => boolean)  # Cell is editable. Pass a callback for
                                    # per-row decisions (e.g. only edit leaf rows in a tree)
  editor?: EditorType               # Editor type
  editTrigger?: EditTrigger         # Per-column trigger override
  editorOptions?: EditorOptions     # Editor configuration
  showEditButton?: boolean          # Show edit button in cell

  # Validation
  onbeforecommit?: (context) => BeforeCommitResult  # Validate/transform
  oncelledit?: (context) => void    # Custom editor callback
}


EDITOR TYPES
------------
EditorType = "text" | "number" | "checkbox" | "select" |
             "combobox" | "date" | "autocomplete" | "custom"


EDIT TRIGGERS
-------------
EditTrigger = "click" | "dblclick" | "button" | "always" | "navigate"

"click"     - Single click to edit
"dblclick"  - Double click to edit (default)
"button"    - Click edit button (requires showEditButton: true)
"always"    - Always in edit mode (spreadsheet-like)
"navigate"  - Arrow keys to move, typing starts edit (Excel-like)


EDITOR OPTIONS
--------------
Options for configuring cell editors.

SHARED (select/combobox/autocomplete):
  options: EditorOption[]           # Static options
  loadOptions: (row, field) => Promise<EditorOption[]>  # Async load
  optionsLoadTrigger: "immediate" | "oneditstart" | "ondropdownopen"
  valueMember: string               # Property for value (default: "value")
  displayMember: string             # Property for display (default: "label")
  allowEmpty: boolean               # Allow null selection
  emptyLabel: string                # Label for empty option

TEXT:
  maxLength: number
  placeholder: string
  pattern: string
  inputMode: "text" | "numeric" | "email" | "tel" | "url"

NUMBER:
  min: number
  max: number
  step: number
  decimalPlaces: number
  allowNegative: boolean

CHECKBOX:
  trueValue: unknown    # Value when checked (default: true)
  falseValue: unknown   # Value when unchecked (default: false)

DATE:
  minDate: Date | string
  maxDate: Date | string
  outputFormat: "date" | "iso" | "timestamp"

AUTOCOMPLETE:
  initialOptions: EditorOption[]    # Show before search
  onSearch: (query, row, signal?) => Promise<EditorOption[]>
  minSearchLength: number           # Min chars before search (default: 1)
  debounceMs: number               # Debounce delay (default: 300)
  multiple: boolean                 # Allow multiple selections
  maxSelections: number             # Max items when multiple=true

COLUMN WIDTH CONTROL
--------------------
By default the grid stretches columns to fill 100% of its container (HTML
table auto-layout). To keep columns at predefined widths, combine per-column
width/min/max/autoWidth with the grid-level `fillerColumn` prop.

Fixed widths + filler:
  const columns = [
    { field: "id",     title: "ID",     width: "80px" },
    { field: "name",   title: "Name",   width: "200px" },
    { field: "email",  title: "Email",  width: "280px" }
  ]
  <QuickGrid items={data} {columns} fillerColumn />

Auto-size small columns to content; let one flex:
  const columns = [
    { field: "id",       title: "ID",       autoWidth: true },
    { field: "status",   title: "Status",   autoWidth: true },
    { field: "description", title: "Description" }  // takes remaining space
  ]
  <QuickGrid items={data} {columns} />

Min/max constraints:
  { field: "name", title: "Name", minWidth: "150px", maxWidth: "400px" }

Notes:
- `width` / `minWidth` / `maxWidth` accept any CSS length (px, %, rem, ch, vw, ...)
- `autoWidth` implements the `width: 1%; white-space: nowrap` header trick;
  don't combine with `width`
- Without `fillerColumn`, any extra space is redistributed to non-fixed columns

AUTOCOMPLETE EDITOR (Async)
---------------------------
const columns = [
  {
    field: "country",
    title: "Country",
    isEditable: true,
    editor: "autocomplete",
    editorOptions: {
      initialOptions: [
        { value: "us", label: "United States" },
        { value: "uk", label: "United Kingdom" }
      ],
      onSearch: async (query, row, signal) => {
        const response = await fetch(`/api/countries?q=${query}`, { signal })
        return response.json()
      },
      minSearchLength: 2,
      debounceMs: 300
    }
  }
]


CUSTOM EDITOR
-------------
For complex editing needs, use custom editor with dialog:

const columns = [
  {
    field: "metadata",
    title: "Metadata",
    isEditable: true,
    editor: "custom",
    showEditButton: true,
    format: (value) => value ? JSON.stringify(value).slice(0, 20) + "..." : "(empty)",
    oncelledit: (context) => {
      // context: { value, row, rowIndex, field, commit, cancel }
      editingContext = context
      dialogOpen = true
    }
  }
]

// In your dialog:
function handleSave() {
  editingContext.commit(newValue)
  dialogOpen = false
}

  editable

Keyboard navigation:

- Escape: Cancel edit
- Tab: Move to next cell
- Typing: Start editing with typed character


VALIDATION (onbeforecommit)
---------------------------
Validate before committing:

const columns = [
  {
    field: "age",
    title: "Age",
    isEditable: true,
    editor: "number",
    onbeforecommit: (context) => {
      // context: { value, oldValue, row, rowIndex, field }
      if (context.value < 0) {
        return { valid: false, message: "Age must be positive" }
      }
      if (context.value > 150) {
        return { valid: false, message: "Age too high" }
      }
      return { valid: true }
    }
  }
]

Return types:
- { valid: true }                    # Accept value
- { valid: false, message: "..." }   # Reject with message
- { valid: true, transformedValue }  # Accept with transformation
- true                               # Accept (shorthand)
- false                              # Reject (no message)
- "Error message"                    # Reject with message


ASYNC VALIDATION
----------------
const columns = [
  {
    field: "email",
    title: "Email",
    isEditable: true,
    editor: "text",
    onbeforecommit: async (context) => {
      const exists = await checkEmailExists(context.value)
      if (exists) {
        return { valid: false, message: "Email already taken" }
      }
      return { valid: true }
    }
  }
]


TRACKING ROW CHANGES
--------------------
<QuickGrid

  editable
  onrowchange={(detail) => {
    // detail: { row, draftRow, rowIndex, field, oldValue, newValue, isValid, validationError }

  }}
/>


INVALID CELLS STATE
-------------------
Track validation errors externally:

<script>
  let invalidCells = $state([])
</script>

<QuickGrid
  items={data}
  columns={columns}
  editable
  bind:invalidCells
/>

{#if invalidCells.length > 0}
  <p>Errors: {invalidCells.map(c => c.error).join(", ")}</p>
{/if}

BEST PRACTICES
--------------
1. Type your data with TypeScript generics
2. Use onbeforecommit for validation (not deprecated validate prop)
3. Use navigate mode for Excel-like experience
4. Load options lazily for performance
5. Use snippets for complex cell rendering


COMMON ISSUES
-------------

Issue: Editor not showing
Solution: Check editable=true on QuickGrid AND column

Issue: Dropdown options not loading
Solution: Check loadOptions returns Promise<EditorOption[]>

Issue: Validation message not showing
Solution: Return { valid: false, message: "..." } from onbeforecommit

Issue: Navigate mode not working
Solution: Set editTrigger="navigate" on QuickGrid

Issue: Checkbox not clickable
Solution: Use checkboxAlwaysEditable prop in navigate mode
