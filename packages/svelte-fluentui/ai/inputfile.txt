INPUTFILE COMPONENT
===================

OVERVIEW
--------
File upload component with drag-drop support, validation, and progress tracking.
Custom implementation inspired by FluentUI Blazor InputFile.


BASIC USAGE
-----------
<script>
  import { InputFile } from "svelte-fluentui"

  function handleFilesSelected(files: File[]) {
    console.log("Selected files:", files)
  }
</script>

<InputFile onFileSelected={handleFilesSelected} />


PROPS
-----
accept?: string                # Accepted file types (e.g., ".pdf,.doc", "image/*")
multiple?: boolean             # Allow multiple files (default: false)
disabled?: boolean
maxFileSize?: number           # Max size in bytes (default: 10MB)
maxFileCount?: number          # Max files when multiple (default: 10)
showDragDropZone?: boolean     # Show drag-drop area (default: true)
uploadFileCallback?: FileUploadHandler  # Async upload function
class?: string
style?: string

CALLBACKS:
onFileSelected?: (files: File[]) => void     # Files selected
onFileUploaded?: (file: File) => void        # Single file upload complete
onFileError?: (file: File, error: string) => void  # Upload/validation error
onCompleted?: () => void                     # All uploads complete


FILE UPLOAD HANDLER TYPE
------------------------
type FileUploadHandler = (
  file: File,
  onProgress: (percent: number) => void
) => Promise<void>


ACCEPT FORMATS
--------------
File extensions:
  accept=".pdf"
  accept=".pdf,.doc,.docx"
  accept=".jpg,.jpeg,.png,.gif"

MIME types:
  accept="image/*"           # All images
  accept="video/*"           # All videos
  accept="audio/*"           # All audio
  accept="application/pdf"   # Specific MIME type

Combined:
  accept="image/*,.pdf"      # Images and PDFs

REAL UPLOAD WITH PROGRESS:
<script>
  async function uploadWithProgress(
    file: File,
    onProgress: (percent: number) => void
  ): Promise<void> {
    return new Promise((resolve, reject) => {
      const xhr = new XMLHttpRequest()

      xhr.upload.addEventListener("progress", (e) => {
        if (e.lengthComputable) {
          onProgress(Math.round((e.loaded / e.total) * 100))
        }
      })

      xhr.addEventListener("load", () => {
        if (xhr.status >= 200 && xhr.status < 300) {
          resolve()
        } else {
          reject(new Error(`Upload failed: ${xhr.status}`))
        }
      })

      xhr.addEventListener("error", () => {
        reject(new Error("Network error"))
      })

      const formData = new FormData()
      formData.append("file", file)

      xhr.open("POST", "/api/upload")
      xhr.send(formData)
    })
  }
</script>

<InputFile
  multiple
  uploadFileCallback={uploadWithProgress}
/>

DRAG AND DROP
-------------
The drag-drop zone:
1. Shows "Drag and drop files here, or" with Browse button
2. Changes appearance when dragging files over
3. Shows "Drop files here" during drag
4. Displays accepted types and max size hints


FILE LIST
---------
After selection, shows list with:
- File name and size
- Progress bar (during upload)
- Status: "Pending", "✓ Completed", "✗ Error message"
- Remove button for each file
- Clear all button


FILE STATUSES
-------------
- pending: File selected, not yet uploaded
- uploading: Upload in progress (shows progress bar)
- completed: Upload successful
- error: Validation or upload error


VALIDATION
----------
Built-in validation checks:
1. File type (accept prop)
2. File size (maxFileSize prop)
3. File count (maxFileCount prop when multiple)

Validation errors trigger onFileError callback.


FORM INTEGRATION
----------------
<script>
  let uploadedFiles: string[] = $state([])

  async function uploadFile(file: File, onProgress: (percent: number) => void) {
    // Upload logic...
    const response = await uploadToServer(file)

  }

  function handleSubmit() {
    // uploadedFiles contains IDs of uploaded files

<form>

    multiple

COMMON ISSUES
-------------

Issue: Files not uploading
Solution: Provide uploadFileCallback prop

Issue: Progress not updating
Solution: Call onProgress callback in upload function

Issue: Wrong file type error
Solution: Check accept prop format

Issue: Drag-drop not working
Solution: Ensure not disabled, check browser support

Issue: Files rejected silently
Solution: Add onFileError callback for error messages

Issue: Multiple uploads not sequential
Solution: Files upload in order; wait for onCompleted
