QUICK PROBLEM SOLVING
==============================================================================

Problem: Component not showing
→ getting-started.txt (check imports)
→ theming.txt (check CSS setup)

Problem: QuickGrid not sorting/filtering
→ quickgrid.txt (check column config)

Problem: Dialog appearing behind other elements
→ dialog.txt (z-index section)

Problem: Toast not showing
→ toast.txt (ToastContainer setup)

Problem: Date format wrong
→ datepicker.txt (format options)

Problem: Autocomplete not searching
→ autocomplete.txt (onSearch callback)

Problem: Layout not responsive
→ layout.txt (Grid/GridItem responsive props)

Problem: Dark mode not working
→ theming.txt (theme setup)

Problem: Icon not loading
→ display.txt (Icon component, fluentui icons)


==============================================================================
NAMING CONVENTIONS
==============================================================================

Property names: camelCase
  horizontalAlign, autoUpdateMode, editTrigger

Property values: lowercase or kebab-case
  "center", "accent", "flex-start", "space-between"

Event handlers: lowercase
  onclick, onchange, oninput, ondismiss

Custom callbacks: lowercase
  onoptionssearch, onrowchange, onbeforecommit
