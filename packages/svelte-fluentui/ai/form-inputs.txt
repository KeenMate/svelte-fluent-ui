FORM INPUT COMPONENTS
=====================

OVERVIEW
--------
Form input components that wrap FluentUI Web Components (<fluent-*>).
All use lowercase event handlers (onclick, onchange, oninput).


==============================================================================
TEXTFIELD
==============================================================================
Wraps: <fluent-text-field>

USAGE:
<script>
  import { TextField } from "svelte-fluentui"
  let value = $state("")
</script>

<TextField bind:value placeholder="Enter text" />

PROPS:
value: string              # Bindable
placeholder: string
disabled: boolean
readonly: boolean
required: boolean
maxlength: number
minlength: number
pattern: string
type: "text" | "email" | "password" | "tel" | "url"
appearance: "outline" | "filled"
size: string
autofocus: boolean

EVENTS:
oninput: (e) => void
onchange: (e) => void
onfocus: (e) => void
onblur: (e) => void

==============================================================================
COMMON PATTERNS
==============================================================================

FORM WITH BINDING:
<script>
  import { TextField, Checkbox, Select, Option, Button, Stack } from "svelte-fluentui"

  let formData = $state({
    name: "",
    email: "",
    newsletter: false,
    country: ""
  })

  function handleSubmit() {
    console.log("Form data:", formData)
  }
</script>

<Stack orientation="vertical" gap="1rem">
  <TextField bind:value={formData.name} placeholder="Name" required />
  <TextField bind:value={formData.email} type="email" placeholder="Email" />
  <Checkbox bind:checked={formData.newsletter}>Subscribe to newsletter</Checkbox>
  <Select bind:value={formData.country}>
    <Option value="">Select country</Option>
    <Option value="us">United States</Option>
    <Option value="uk">United Kingdom</Option>
  </Select>
  <Button appearance="accent" onclick={handleSubmit}>Submit</Button>
</Stack>


CONTROLLED INPUT:
<script>
  let value = $state("")

  function handleInput(e) {
    value = e.target.value.toUpperCase()
  }
</script>

<TextField {value} oninput={handleInput} />


VALIDATION PATTERN:
<script>
  let email = $state("")
  let error = $derived(
    email && !email.includes("@") ? "Invalid email" : ""
  )
</script>

<TextField
  bind:value={email}
  placeholder="Email"
  class={error ? "error" : ""}
/>
{#if error}
  <span class="error-message">{error}</span>
{/if}


==============================================================================
EVENT HANDLING
==============================================================================

All events use lowercase names (Svelte 5 convention):
- onclick
- onchange
- oninput
- onfocus
- onblur
- onkeydown
- onkeyup

Example:
<TextField
  value={text}
  oninput={(e) => text = e.target.value}
  onkeydown={(e) => {
    if (e.key === "Enter") submit()
  }}
/>


==============================================================================
ACCESSIBILITY
==============================================================================

All FluentUI components have built-in accessibility:
- Proper ARIA attributes
- Keyboard navigation
- Focus management
- Screen reader support

Add labels for better accessibility:
<label>
  Name
  <TextField bind:value={name} />
</label>

Or use aria-label:
<TextField bind:value={name} aria-label="Your name" />


==============================================================================
STYLING
==============================================================================

FluentUI inputs use CSS custom properties (design tokens):
- --neutral-fill-input-rest
- --neutral-stroke-input-rest
- --accent-fill-rest

Override with CSS:
fluent-text-field::part(control) {
  border-radius: 8px;
}


==============================================================================
COMMON ISSUES
==============================================================================

Issue: Value not updating
Solution: Use bind:value for two-way binding

Issue: Event not firing
Solution: Use lowercase event names (oninput not onInput)

Issue: Styling not applying
Solution: Use ::part() selectors for shadow DOM
