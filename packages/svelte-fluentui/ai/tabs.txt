TABS COMPONENT
==============

OVERVIEW
--------
Tab navigation with panels.
Uses fluent-tabs/fluent-tab web components with custom enhancements.
Supports horizontal and vertical orientation.


BASIC USAGE
-----------
<script>
  import { Tabs, Tab } from "svelte-fluentui"
</script>

<Tabs>
  {#snippet childContent()}
    <Tab id="tab1" label="Overview">
      {#snippet content()}
        <p>Overview content here</p>
      {/snippet}
    </Tab>

    <Tab id="tab2" label="Details">
      {#snippet content()}
        <p>Details content here</p>
      {/snippet}
    </Tab>

    <Tab id="tab3" label="Settings">
      {#snippet content()}
        <p>Settings content here</p>
      {/snippet}
    </Tab>
  {/snippet}
</Tabs>


TABS PROPS
----------
id?: string
class?: string
style?: string
orientation?: "horizontal" | "vertical"  # Tab direction (default: "horizontal")
activeId?: string                        # Initially active tab ID
showActiveIndicator?: boolean            # Show active indicator (default: true)
overflow?: { label: string, onclick?: () => void }[]  # Overflow menu items
moreButtonId?: string
styleMoreValues?: string

CALLBACKS:
ontabchange?: (detail: TabChangeDetail) => void


TAB PROPS
---------
id?: string                    # Required for active tab tracking
label?: string                 # Tab label text
disabled?: boolean
ariaLabel?: string
visible?: boolean              # Show/hide tab (default: true)
icon?: SlotType               # Icon snippet
header?: SlotType             # Custom header (replaces label)
content?: SlotType            # Tab panel content
childContent?: SlotType       # Alternative content slot
labelEditable?: boolean       # Enable inline label editing (default: false)
showClose?: boolean           # Show close button (default: false)
data?: Record<string, unknown> # Custom data passed to ontabchange

CALLBACKS:
oncloseclick?: () => void


TAB CHANGE EVENT
----------------
<script>
  function handleTabChange(detail) {
    console.log("Active tab:", detail.tabId)
    console.log("Tab data:", detail.data)
  }
</script>

<Tabs ontabchange={handleTabChange}>
  {#snippet childContent()}
    <Tab id="tab1" label="Tab 1" data={{ section: "overview" }}>
      {#snippet content()}Content 1{/snippet}
    </Tab>
    <Tab id="tab2" label="Tab 2" data={{ section: "details" }}>
      {#snippet content()}Content 2{/snippet}
    </Tab>
  {/snippet}
</Tabs>

<script>

<Tabs activeId={activeTab}>
  {#snippet childContent()}

      {#snippet content()}Second content{/snippet}
    </Tab>

CLOSABLE TABS
-------------
<script>
  let tabs = $state([
    { id: "tab1", label: "Document 1" },
    { id: "tab2", label: "Document 2" },
    { id: "tab3", label: "Document 3" }
  ])

  function closeTab(tabId: string) {
    tabs = tabs.filter(t => t.id !== tabId)
  }
</script>

<Tabs>
  {#snippet childContent()}
    {#each tabs as tab}
      <Tab
        id={tab.id}
        label={tab.label}
        showClose
        oncloseclick={() => closeTab(tab.id)}
      >
        {#snippet content()}
          Content for {tab.label}
        {/snippet}
      </Tab>
    {/each}
  {/snippet}
</Tabs>

DYNAMIC TABS
------------
<script>
  let tabs = $state([
    { id: "1", label: "Tab 1" },
    { id: "2", label: "Tab 2" }
  ])

  function addTab() {
    const newId = String(tabs.length + 1)
    tabs = [...tabs, { id: newId, label: `Tab ${newId}` }]
  }
</script>

<button onclick={addTab}>Add Tab</button>

<Tabs>
  {#snippet childContent()}
    {#each tabs as tab}
      <Tab id={tab.id} label={tab.label}>
        {#snippet content()}
          Content for {tab.label}
        {/snippet}
      </Tab>
    {/each}
  {/snippet}
</Tabs>

OVERFLOW MENU
-------------
For many tabs, use overflow prop to show excess tabs in a menu:

<Tabs
  overflow={[
    { label: "Extra 1", onclick: () => activateTab("extra1") },
    { label: "Extra 2", onclick: () => activateTab("extra2") }
  ]}
>
  {#snippet childContent()}
    <Tab id="main" label="Main">
      {#snippet content()}Main content{/snippet}
    </Tab>
  {/snippet}
</Tabs>

Shows a "+N" badge that opens a dropdown menu.


STYLING
-------
Tabs use fluent-tabs web component.

CSS Classes:
- .tab-wrapper - Tab element wrapper
- .editable-label - Editable label container
- .fluent-tab-close - Close button

Override with ::part() selectors:
fluent-tabs::part(tablist) {
  border-bottom: 2px solid var(--neutral-stroke-rest);
}

fluent-tab::part(control) {
  padding: 1rem 1.5rem;
}

DOCUMENT TABS:
<Tabs>
  {#snippet childContent()}
    {#each openDocuments as doc}
      <Tab
        id={doc.id}
        label={doc.name}
        showClose
        oncloseclick={() => closeDocument(doc.id)}
        data={{ documentId: doc.id }}

        {/snippet}
      </Tab>
    {/each}
  {/snippet}
</Tabs>


COMMON ISSUES
-------------

Issue: Tab content not showing
Solution: Use {#snippet content()} inside Tab component

Issue: Active tab not tracked
Solution: Add unique id prop to each Tab

Issue: Tab change not firing
Solution: Check ontabchange callback on Tabs component

Issue: Vertical tabs not working
Solution: Set orientation="vertical" on Tabs

Issue: Close button not visible
Solution: Add showClose prop to Tab
